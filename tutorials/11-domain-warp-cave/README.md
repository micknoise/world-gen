# Domain Warp Cave

This tutorial displaces each noise sample's coordinates with a second independent noise field before reading the primary field. That displacement — domain warping — folds and twists the cave geometry into organic forms that plain noise cannot produce.

## What It Explains

- how domain warping works by redirecting the lookup coordinates before sampling
- why using two independent offset fields produces more varied distortion than one
- how warp strength controls the degree of twist from subtle to completely fragmented

## Good Uses

- alien caverns
- twisted underground tunnel networks
- lava tube systems
- ancient ruin chambers with warped interiors

## Limits

- warp strength above roughly 3–4 produces heavily fragmented results
- the exact layout shape is not designable in advance
- connectivity is not guaranteed at high warp or high threshold settings
