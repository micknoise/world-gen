# Cellular Automata Cave

This tutorial begins with random noise and repeatedly applies a neighborhood rule to decide whether each tile should become wall or floor.

## What It Explains

- how local rules produce large organic forms
- how repeated smoothing changes map density
- why cave generators often begin with noise instead of rooms

## Good Uses

- cave systems
- lava caverns
- underground biomes

## Limits

- disconnected areas are common
- the algorithm does not guarantee traversal paths
- different rules can quickly collapse the cave into too much wall or too much floor
