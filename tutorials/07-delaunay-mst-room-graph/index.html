What this shows

This places room centers, builds a Delaunay-style neighbor graph, then keeps only the minimum spanning tree plus a few optional extra edges. It is a connection plan for rooms rather than a carved dungeon by itself.

  • Good for: sparse, readable room graphs and route planning
  • Watch for: graph edges still need to become actual corridors later
