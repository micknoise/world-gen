# Rectangle Packing Rooms

This tutorial focuses on a basic room-placement problem: keep placing rectangles until you run out of space or hit the target count.

## What It Explains

- how non-overlap checks work
- how room density affects success rate
- why placement and connection are usually separate stages

## Good Uses

- room layout planning
- prefab placement concepts
- early-stage dungeon structure

## Limits

- this is a placement strategy, not a full world generator
- room count becomes unstable in crowded layouts
- corridors are only implied unless added later
