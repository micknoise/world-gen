# BSP Dungeon

This tutorial shows how recursive subdivision can create a clear room-and-corridor dungeon.

## What It Explains

- how recursive partitioning reserves space for rooms
- how room centers become connection targets
- why tree structure makes corridor generation easier

## Good Uses

- classic dungeon floors
- tactical combat maps
- tutorial examples where layout readability matters

## Limits

- rooms tend to be rectangular
- results can feel too regular without extra variation
- corridor routing is simple unless additional rules are added
