# Wave Dungeon

This tutorial superposes random plane waves at different angles and frequencies. Where enough waves arrive in phase and their crests reinforce each other, the combined value exceeds the threshold and becomes floor. No noise function is used at all — rooms and passages emerge from pure trigonometry.

## What It Explains

- how constructive interference between waves produces concentrated high-value regions
- why a small number of waves creates bold regular patterns while more waves produce complex irregular rooms
- how frequency range and threshold jointly control room size and density

## Good Uses

- sci-fi or arcane facility layouts
- crystalline or circuit-board-like spaces
- level themes where periodicity and symmetry fit the setting

## Limits

- visible periodicity is unavoidable with few wave sources
- the layout emerges from mathematics rather than design intent and cannot be pre-planned
- does not generate any explicit path or graph structure
