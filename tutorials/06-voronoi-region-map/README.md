# Voronoi Region Map

This tutorial assigns every tile in a grid to the nearest site to create a territory or biome map.

## What It Explains

- how nearest-site assignment creates regions
- how seed count changes region size
- why region generation is different from path generation

## Good Uses

- biome maps
- territory maps
- district ownership
- influence zones

## Limits

- edges are geometric, not naturally shaped
- traversal routes still need a second algorithm
- terrain realism needs more than nearest-site assignment alone
