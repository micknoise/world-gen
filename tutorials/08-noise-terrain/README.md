# Noise Terrain Map

This tutorial samples layered noise and converts it into a simple terrain map.

## What It Explains

- how continuous noise creates broad terrain variation
- how thresholds convert elevation into named terrain bands
- why shaping functions help raw noise feel more map-like

## Good Uses

- overworlds
- islands
- terrain masks
- biome foundations

## Limits

- noise alone does not produce roads, rivers, or settlements
- terrain bands need careful threshold tuning
- advanced terrain still needs erosion and hydrology passes
