JavaScript Tutorials

World generation algorithms rendered from shared JSON.

These tutorials focus on clarity: one algorithm, one environment object, one Canvas demo. Each example is designed to show how the algorithm works and what kind of map it produces.

01

Random Walk Dungeon

Carves loose cave-like floor space by repeatedly stepping through a grid.

 02

Cellular Automata Cave

Smooths random noise into organic cave walls and open chambers.

 03

BSP Dungeon

Splits the map recursively into partitions, then places rooms and corridors.

 04

Quadtree Region Split

Subdivides a world into sectors that can become districts, lots, or zones.

 05

Rectangle Packing Rooms

Places non-overlapping rooms and links them into a simple layout graph.

 06

Voronoi Region Map

Assigns tiles to the nearest seed to create territories, biomes, and borders.

 07

Delaunay + MST Room Graph

Builds a clean connection network between room centers or settlements.

 08

Noise Terrain Map

Turns sampled noise into land, coast, plains, and mountain regions.

Shared approach

Every tutorial exports an environment JSON object before drawing. That keeps the algorithm separate from the renderer and makes the data portable to other engines.

See tutorial-specification.md for the full project specification.
